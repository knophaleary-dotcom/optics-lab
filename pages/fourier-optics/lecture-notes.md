### 核心概念

**六句话记住傅里叶光学：**

1. 光场可以拆成平面波（频率分量）
2. 自由空间传播 = 每个频率分量乘相位因子（角谱传递函数）
3. **远场衍射图案 = 孔径函数的傅里叶变换**
4. 透镜焦平面 = 频谱面（光学傅里叶计算机）
5. 成像 = 频谱传递与合成；滤波 = 在频谱面改幅度/相位
6. **DOE = 精心设计的频谱面相位板**（GS算法是它的"编译器"）

### 角谱法（全书最重要的公式）

自由空间传播的传递函数：

$$ H(f_x, f_y; z) = \exp\left( i \frac{2\pi}{\lambda} z \sqrt{1 - \lambda^2(f_x^2 + f_y^2)} \right) $$

- $\lambda^2 f^2 < 1$ → **传播波**（仅相位变化）
- $\lambda^2 f^2 = 1$ → 截止频率（对应90°方向）
- $\lambda^2 f^2 > 1$ → **倏逝波**（指数衰减）

### 夫琅禾费衍射

$$ U(x,y,z) = \frac{e^{ikz}}{i\lambda z} \exp\left(i\frac{k}{2z}(x^2+y^2)\right) \iint U(\xi,\eta,0) \exp\left(-i\frac{2\pi}{\lambda z}(x\xi+y\eta)\right) d\xi d\eta $$

**远场图案 = 孔径的傅里叶变换。** 坐标关系：$f_x = x/(\lambda z)$, $f_y = y/(\lambda z)$。

### 透镜的傅里叶变换性质

薄透镜相位变换：$t(x,y) = \exp(-ik(x^2+y^2)/2f)$

**透镜后焦面 = 输入场的傅里叶变换**（乘二次相位因子）。在2f系统中是精确变换。

### DOE设计的GS算法

Gerchberg-Saxton迭代：

1. 随机初始化DOE相位
2. 空域：幅度=照明，相位=当前DOE
3. FFT → 频域：保留相位，幅度换成目标图案
4. IFFT → 空域：保留相位，幅度换回照明
5. 评估收敛，否则回到步骤2

### 达曼光栅3×3

3分束1D过渡点：$x_1 = 0.32489$, $x_2 = 0.67511$

2D可分离：$\phi(x,y) = \phi_{1D}(x) + \phi_{1D}(y)$

**台阶量化效率**：$\eta = \text{sinc}^2(1/L)$ → $L=2$: 40%, $L=4$: 81%, **$L=8$: 95%**, $L=16$: 99%
